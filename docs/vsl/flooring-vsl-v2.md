# Flooring VSL v2: the Client Flow System

Written 2026-10-28 for an AI voiceover (ElevenLabs). Structure set by Jonathan: curious hook → "they understand me" → proof of the dream outcome → the dream situation → the pains → the mechanism (short, no feature list) → guarantee and offer → CTA.

**Positioning in one line:** a flooring client flow system we build and install in their business, that they own. Not lead gen, not an answering service, not a CRM, not an agency.

**Rules kept:** no price; no guarantee failure terms; never say or imply flooring is new to FieldBuilt; no "I install every one myself" or capacity lines; the 130 / 13 / 9 numbers are only "a home services company"; the 4 in 10 stat is Service Direct's 2022 homeowner survey.

Written for the ear: short sentences, one idea each, numbers spelled the way they're said, no dashes. About 280 words, roughly 90 seconds.

**Guarantee and offer**
